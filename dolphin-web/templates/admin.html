Admin Access
Emails with admin access are set in app.py → ADMIN_EMAILS.
To add or remove admin accounts, edit the ADMIN_EMAILS list in app.py and restart the server. This keeps admin access server-controlled and secure.
Allowed Extra Emails
Non-Chadwick emails allowed to sign in are set in ALLOWED_EXTRA_EMAILS in app.py.
To allow a guest or parent account, add their email to ALLOWED_EXTRA_EMAILS in app.py.
